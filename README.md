# Predicting future <em>Agrilus</em> -- <em>Quercus</em> analysis

This branch contains the original code used to generate the data for Hernandez-Gutierrez et al. (2026), "Combined phylogenetic and geographic data can predict plant – pest interactions with high accuracy" (doi: 10.1111/nph.71306). These analyses explore how readily available phylogenetic and geographical information can be used to predict previously unobserved host – pest interactions, through relatively simple multilevel Bayesian models. Our aim is to implement a broadly applicable approach for identifying potentially harmful host – pest interactions, and help to prioritise counter measures against threats worldwide.


## Repository structure and contents

> Please note that the `main` branch mirrors these same analyses, but with refactored code for better readability, reusability, and efficiency. If you intend to use or adapt this code for your own work, you may prefer to use the `main` branch instead.

In this repository, you will find:
* `analysis/`: R scripts used to perform the analyses and produce the results reported in the paper.
* `data/`: Input data used in the scripts and data generated during the analyses.
